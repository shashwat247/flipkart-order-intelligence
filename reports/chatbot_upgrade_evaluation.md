## Old behavior vs. new behavior

**Old:** three intents (`policy`, `return_risk`, `product_category`), a policy question with no grounded chunk was refused with the same wording as an off-topic question, no product catalog, no cross-turn slot memory beyond an order id.

**New:** the same three graph lanes plus a `conversational` lane for ordinary conversation; 11 additional fine-grained conversational intents (greeting/general_help/unsupported/refund/exchange/delivery/damaged_product/cancellation/comparison/explanation/product_lookup) that map onto those four lanes; a 54-product synthetic catalog searchable by both structured filter and semantic similarity; free-text order-feature slot extraction that accumulates across turns; and pronoun/follow-up resolution against the last grounded topic.

## Known, honestly-reported limitation

Retrieval quality is a pre-existing property of the sentence-level chunking and `all-MiniLM-L6-v2` embeddings (unchanged by this upgrade) -- a handful of single-sentence chunks score closer to a *neighbouring* category's rule than the correct one for a short query (e.g. "return window for shoes" can retrieve the electronics-window sentence ahead of the footwear one, by roughly 0.002 cosine similarity). The agent still only ever quotes and cites whatever it actually retrieved -- it never fabricates a rule -- so this is a retrieval-recall limitation to disclose, not an agent-architecture defect this upgrade introduced or was scoped to fix.
